# ScrollVerse Continuity Vault

> Private, sanitized continuity archive for owner-reviewed ScrollVerse workflows, evidence maps, route inventories, recovery guidance, and validation records.

## Purpose

This repository protects reviewable continuity material for recovery, portability, source integrity, and owner-reviewed auditability.

## Never stored here

Credentials, access tokens, private keys, cookies, production database dumps, payment data, private analytics, user uploads, or unreviewed external source.

## Curated export standard

Only reviewed documentation, public route inventories, reusable workflow references, non-secret schema metadata, source registers, and dated recovery checklists may be added. Every broader source export requires staged-file and secret review.

## Restore rule

A restored workspace must run dependency installation, TypeScript validation, the regression suite, and route checks before deployment consideration.

## Integration boundary

An owner-installed Docker for GitHub Copilot app was shown at repository creation. Its presence is recorded for review; it does not authorize access to secrets, user data, production credentials, or unreviewed source.
